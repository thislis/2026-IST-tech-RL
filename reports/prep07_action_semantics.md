# PREP-07 Action Semantics Report

고정 build의 열린 내부 위치에서 `unit_0`을 사용해 1 step displacement를 측정했다.

- seed: `40707`
- spawn normalized position: `(0.0625, 0.9375)`
- 측정 anchor: `(0.18270828, 0.81729269)`
- anchor까지 `(1,-1)` 51 steps 이동
- map bounds: `24×24`

## 크기와 정규화

| 입력 action | normalized displacement | world displacement | 결과 |
| --- | ---: | ---: | --- |
| `(0,0)` | `0` | `0` | 정지 |
| `(0.1,0)` | `0.0033333302` | 약 `0.08` | 이동 |
| `(1,0)` | `0.0033333302` | 약 `0.08` | 작은 vector와 동일 |
| `(2,0)` | `0.0033333302` | 약 `0.08` | Python에서 1로 clip, 동일 |

Unity는 non-zero vector를 normalize하므로 magnitude는 속도 제어가 아니다.
Collector의 world displacement `0.08`은 `speed 4 × fixedDeltaTime 0.02`와 일치한다.

## 8방향

| 방향 | action | measured delta (normalized) | magnitude |
| --- | --- | --- | ---: |
| E | `(1,0)` | `(0.00333333, 0)` | `0.00333333` |
| NE | `(1,1)` | `(0.00235704, 0.00235701)` | `0.00333333` |
| N | `(0,1)` | `(0, 0.00333333)` | `0.00333333` |
| NW | `(-1,1)` | `(-0.00235702, 0.00235701)` | `0.00333332` |
| W | `(-1,0)` | `(-0.00333333, 0)` | `0.00333333` |
| SW | `(-1,-1)` | `(-0.00235702, -0.00235701)` | `0.00333332` |
| S | `(0,-1)` | `(0, -0.00333333)` | `0.00333333` |
| SE | `(1,-1)` | `(0.00235704, -0.00235701)` | `0.00333333` |

모든 측정 방향의 action/delta cosine은 `0.9999999` 이상이고, 대각선도 축 방향과
같은 총 이동량을 가졌다. 벽이나 금지 영역에서는 충돌 계산 때문에 실제 이동량이
줄거나 0이 될 수 있지만, action의 의미 자체는 위와 같다.

## 정책 adapter 결론

- 연속 출력을 유지한다면 0 근처의 정확한 정지와 방향만 의미가 있다.
- categorical baseline은 `NoOp + 8방향`의 9-way action으로 손실 없이 변환할 수 있다.
- action 범위 밖 값은 Python wrapper에서 `[-1,1]`로 clip되지만, 모델 출력도 계약상
  해당 범위를 지켜야 한다.
