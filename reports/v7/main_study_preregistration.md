# v7 본실험 학습 및 dev 평가 등록 — 2026-09-19

사용자가 v7 대규모 본실험 스크립트를 요청했고, v7-2는 현재 구현된 PPO 모델을
3개 독립 시드 × 200만 환경 스텝으로 포함하도록 지정했다. 이 문서는 실행 전에
정한 범위이며, 실험 완료나 성능 향상을 보고하는 문서가 아니다.

## 구성과 예산

- v7-1: A0 MLP, A1 파라미터 수 대응 MLP, A2 차수 보존 재배선, A3 실제 FlyWire 부분 회로.
  각 모델은 시드 11, 22, 33, 44, 55에서 2,000,000 step. 총 20개, 40,000,000 step.
- v7-2: F1 고정 전뇌 특징 + PPO 출력층, `S0_semantic_retina`, 한 유닛 slot 0,
  `fly64_proxy_v1`, action repeat 1, 가소성 비활성, `fixed_scripted_active_slots_v2`.
  시드 11, 22, 33에서 2,000,000 step. 총 3개, 6,000,000 step.
- 각 버전의 학습을 모두 수행한 뒤 해당 버전의 dev 평가를 수행한다. 동시 Unity 실행은 하나다.
- 파일럿 체크포인트에서 이전하지 않는다. 새 학습 부분을 초기화하며 고정 인코더/상대는
  기존 해시로 고정한 `checkpoints/win_70_vs_scripted.pt`를 사용한다.
- 모델별 전체 설정은 `configs/v7/main_study/*.yaml`, 순서는 `*_queue.json`에 고정한다.
  별도 experiment ID의 `_main_2m_v1` 접미사로 파일럿 로그·체크포인트를 보존한다.

## 공통 조건과 선택 규칙

그래프/원본 데이터/Unity 실행 파일/인코더/상대/맵 분할/인과성 gate의 해시를 기존
검증 코드로 검사한다. 모델·학습 설정과 orchestration 파일도
`main_study_registration.json`에 고정한다. 등록 소스 보관본의 해시를 검사하며,
코드나 설정을 바꾼 실행을 동일 실험에 자동 합치지 않는다.

학습 맵은 기존 등록 train 분할, reward/PPO/난수 분리와 상대 전환 일정은 기존 설정을
유지한다. scripted/weak/target 혼합은 20만까지 65/25/10%, 60만까지 20/30/50%,
이후 10/0/90%다. 성적에 따른 조기 성공 종료, 실패 맵 우선 표집, 시드 제외는 하지 않는다.

모델 선택은 **등록 예산 200만 step의 latest checkpoint**다. dev 승률로 중간 체크포인트를
고르지 않는다. 각 실행에서 dev 41000–41029의 A/B 두 진영, 총 60경기를 고정 target
상대와 수행한다. 총 평가량은 23 × 60 = 1,380경기이며 학습 step에 포함하지 않는다.
승패는 terminal `winner`로 측정한다. truncated/watchdog 경기를 승패로 임의 변환하지 않는다.

평가 결과에는 모델·시드별 승률, 무승부율, paired-map bootstrap 신뢰구간을 남긴다.
단일 시드의 맵 신뢰구간은 독립 학습 시드 전체를 고려한 구조 개선 검정이 아니다.
본실험 해석에는 시드별 결과를 모두 포함한 추가 비교 분석이 필요하다.

## 중단·재개

오류 시 전체 순서를 중단하고 로그·실패 상태를 보존한다. 정상 종료 신호는 현재 자식
실행에 전달하며 학습은 저장 후 끝낸다. 같은 시작 명령은 완료된 실행을 재사용하고
미완료 본실험 체크포인트에 `--resume`를 적용한다. Unity 물리 상태는 이어붙이지 않고
새 경기에서 재개한다. 설정/소스/seed/예산 불일치나 기존 기록에 체크포인트가 없는 경우
자동 덮어쓰기 없이 중단한다. 불완전한 평가의 모델은 60경기를 다시 실행한다.

중복 통합 실행은 lifetime lock으로 차단한다. 각 버전은 queue/evaluation lock을 잡고,
학습 코드는 개별 run lock을 잡는다. 두 버전을 병렬로 실행하지 않는다.

## 해석 범위 및 비용

v7-1은 계획서 §9.2의 A0/A1/A2/A3 × 5시드 학습 비교를 실행한다. A1/A3의 학습 파라미터
차이는 `main_study_parameter_counts.json`에 기록하며 ±5% 조건을 검사했다.
계산량·지연 시간이 동일하다는 뜻은 아니다.

v7-2는 사용자가 지정한 현재 F1 모델의 장기 학습 확장이다. B2/B3 대조군은 구현되지
않았으므로 생물학적 전뇌 배선의 우월성을 판정하는 완전한 대조 연구로 부르지 않는다.
F0 추가 실행, F2, 다섯 유닛 제어, confirmation, 최종 held-out test, export는 이 큐에 없다.
최종 test는 별도의 모델 잠금·선택 절차 후 기존 evaluator로 수행해야 한다.

실제 소요 시간은 4,600만 환경 step의 처리량, PPO 업데이트와 1,380경기 평가 비용에
따라 달라진다. 짧은 파일럿 처리량만으로 완료 일시를 보장하지 않는다. 이 작업에서는
실행 설정·정적 검사·모델 생성·회귀 테스트까지 수행하며 장기 학습을 자동 시작하지 않는다.
