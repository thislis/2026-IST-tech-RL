01 / PERFORMANCE

누가 가장 좋았는가

순위는 승점률=(승리+0.5×무승부)/경기 수. 모두 같은 상대와 같은 횟수로 경기해 상대별 평균과 전체 승점률이 같다.

전체 순위모델승 / 무 / 패승점률승률Blue / Red 승점률반납 추정 / 경기추론 p50

필터는 행 표시만 바꿉니다. 승률과 순위의 분모는 항상 전체 리그 200경기입니다. 추론은 팀 5개 행동 생성 시간(ms), 각 경기의 처음·중간·마지막 chunk를 표본 추출한 값이며 CPU 8병렬 환경의 부하가 포함됩니다.

프로젝트 선택

현 시점의 기준선: v4와 v6

두 모델 모두 상위 5개 밖의 상대에게 160전 160승이었다. v4는 더 단순한 잔차 보정 기준선, v6는 상태·이력을 활용하는 확장 기준선으로 유지할 수 있다. 팀 추론 표본 p50은 v4 5.29 ms, v6 8.27 ms, v7 Rewired 9.31 ms였다.

이는 개발 역할을 제안한 것이다. 추론 시간은 서로 다른 경기 상태와 동시 실행 부하를 포함한 표본이다. 학습 예산·시드·planner 소스가 다르므로 v4가 더 학습 효율적이라는 인과 결론은 내리지 않는다. 평균 reward가 높은 v6를 동률의 단독 우승자로 바꾸지도 않는다.

제출형 내부 비교

v10이 앞서지만 v9 대비 개선은 미확정

v10의 승점률 37.0%, v9는 36.5%. 직접 대결은 5승 5패다. 무작위 정책 상대도 v10은 4승 6패, v9는 5승 5패여서 다음 학습 전에 기초 수행 능력 검증이 필요하다.

v8 C1 13.0%, v8 Flat 15.5%보다 높은 성적이다. 이 리그에는 v10 C0와 v9 A/C가 없으므로 critic 변경이나 arm 선택 효과를 재검증한 결과는 아니다.

02 / MATCHUPS

누가 누구에게 강했는가

셀을 클릭하면 해당 대진 10경기의 진영별 성적과 5회 반복 결과가 표시됩니다. 숫자는 행 모델이 열 상대에게 얻은 승점률(%)입니다.

높은 승점률50% · 균형낮은 승점률대진당 10경기 · 각 진영 5경기

상위 5개는 하나의 강한 집단

v4·v6·v7 Rewired는 나머지 16개 상대에 전승했다. v5는 확장 추격 FSM에, v7 FlyWire는 기본 FSM에 한 번씩 졌다. 상위권 사이의 모든 대진은 50%다.

단순한 일렬 순위로는 부족하다

기본 FSM → 돌격 → 특수 아이템 → 기본 FSM의 순환이 관측됐다. 각각 7:3, 6:4, 7:3이다. 한 상대에게 강한 전략이 모든 상대에게 강한 것은 아니다.

관측된 순환 1개. 특히 6:4는 소표본이므로 확정적 상성으로 단정하지 않는다.

‘weak’라는 이름을 믿으면 안 된다

scripted-weak는 이번 규칙 기반 1위(70.0%)다. 코드상 차이는 기본 FSM의 추격 반경 5 대신 12를 쓴다는 점이다.

이름은 실험 이력이다. 반경 12가 항상 유리하다는 결론에는 동일 조건의 반경별 실험이 필요하다.

03 / BEHAVIOR & MECHANISM

잘 통했던 행동과 반복된 실패

‘실제 출력’, ‘관측으로 추정한 사건’, ‘코드에서 확인한 설계’를 구분합니다. 경기 로그는 행동을 보여주지만 정책의 의도까지 증명하지 않습니다.

반납으로 연결된 행동이 성적과 함께 높았다

가로: 경기당 반납 추정 사건 수 · 세로: 리그 승점률. 점에 마우스를 올리거나 누르면 모델 정보를 볼 수 있습니다. 상관관계 그림이며 인과효과 추정이 아닙니다. 경기 길이 차이는 아래 모델 카드의 1,000 step당 수치로 보완합니다.

코드에서 확인

상위권의 공통 설계

  1. 역할 분담: worker 3명 + guard 2명.
  2. 명시적 목표: 획득 → 창고 귀환 → 반납 → 재탐색.
  3. 상태 유지: 목표·경로·실행 이력을 기억.
  4. 제한된 보정: planner 동작에 신경망 잔차를 결합. v5~v7은 한 step에서 최대 한 유닛을 보정하는 설계.
가장 유력한 설명

일관된 이동 목표와 역할 분담이 수집·반납의 완주를 도왔을 가능성이 높다.

단, 이 리그에는 각 모델과 정확히 같은 planner를 사용한 ‘잔차 제거’ 대조군이 없다. 신경망의 기여나 그래프 연결 구조의 효과는 아직 분리되지 않았다.

행동 로그

상위권: 분산 이동과 안정된 방향

5개 모델의 전원 동일 행동 비율은 경기 평균 약 0.3~0.8%. 큰 방향 전환은 약 1.7~1.9%, 반납 추정은 약 20.7~21.1회였다.

상위권도 장시간 경기에서는 정지 행동이 늘 수 있다. 경기 평균과 모든 step을 합친 정지율은 다르며, 하나를 다른 지표처럼 비교하지 않는다.

행동 로그

v8: 팀이 함께 한 방향으로 쏠림

C1의 전원 동일 행동은 거의 100%, Flat은 약 97%. 전체 유닛-step 출력 중 C1은 북동 약 98.8%, Flat은 남동 약 94.3%에 집중됐다.

입력에 자기 유닛 ID가 없는 결정론적 정책에서, 같은 관측의 대칭성을 깨지 못하는 것이 가능한 원인이다. 고정 방향만으로 충돌 원인을 확정하지는 않는다.

행동 로그

v9·v10: 다양성은 있지만 완주가 부족

전원 동일 행동은 거의 0%이고 이동 관측 비율은 약 85%다. 그러나 큰 방향 전환 비율이 약 45~47%, 반납 추정은 1.4~2.1회에 그쳤다.

확률적 행동 출력과 일치하는 현상이다. ‘탐색이 잘 됐다’거나 ‘협업을 배웠다’는 증거는 아니다. 목표 유지와 귀환 성공을 따로 측정해야 한다.

모델별 행동 카드

반납 수치는 정확한 게임 이벤트 로그가 아니라 관측 proxy입니다.

빈손→배터리 전환은 획득 추정, 배터리→빈손과 점수 증가가 같은 전이에서 일어나면 반납 추정으로 셉니다. 동시에 여러 유닛이 반납하면 한 사건으로 집계될 수 있습니다. 텔레포트 추정은 긴 위치 변화이며 사망 수가 아닙니다. 기존 backtrack 지표는 아군 필터 없이 모든 슬롯을 집계하므로 이 보고서의 모델별 주장에서는 제외했습니다.

05 / WHAT THIS LEAGUE DOES & DOES NOT PROVE

다음 결정을 바꿀 중요한 한계

실행 완료와 실험 타당성은 별개입니다. 결과가 적용되는 조건을 명시해야 다음 버전에서 같은 오해를 반복하지 않습니다.

우선 확인

승패 판정과 배터리 점수는 다르다

이번 승패는 제공 runner의 팀 누적 raw reward로 판정했다. 반면 프로젝트의 대회 규격 정리는 학습 보상과 대회 점수의 구분을 명시한다. 두 문서·구현의 정합성 확인이 필요하다.

2,100경기의 종료 전이 직후 관측 점수를 복원해 비교한 진단이다. 공식 서버의 최종 판정으로 인증된 값은 아니다. 종료 직전 기록으로 비교하면 반대인 경기는 100개였지만, 마지막 전이를 반영하면 95개다. 원래 리그 순위는 수정하지 않았다.

돌격형: 평균 reward 차이 +3,505.9, 승률 63.0%, 반납 추정 0회. 거대한 reward 평균만으로 가장 좋은 정책이라고 판단하면 안 된다.

로그 직접 검증

1,050개 초기 배치, 그러나 벽 구조는 하나

2,100경기의 최초 맵 snapshot을 검사했다. 양 진영 교대 1,050세트 모두 초기 전체 관측 해시가 일치했다. 배터리 마스크는 1,050종, 창고 마스크는 5종, 벽 마스크는 1종이다.

따라서 ‘모든 경기가 같은 초기 관측’은 아니다. 동시에 새로운 미로 구조에 대한 일반화를 검증한 것도 아니다.

마스크 다양성은 초기 unit_0 그래픽의 채널별 해시로 확인했다. full observation hash는 보이는 초기 상태의 동일성만 확인하며, 내부 난수 상태나 완전한 궤적 재현성을 증명하지 않는다. 원래 로그의 map_seed_verified=false 표시는 보존했다.

① 입력·상태·추론 규칙이 서로 다르다

legacy와 v7 계열은 공개 유닛 이름을 통해 자기 위치·역할을 연결하고 상태를 유지한다. v8 competition과 v9/v10은 ID·reset callback·planner 없이 vector와 graphic만으로 행동한다. 규칙 기반 상대도 ID를 사용한다. 같은 입력 계약의 하위 리그와 전체 시스템 리그를 별도로 보고해야 한다. 특히 동일 클래스 유닛의 관측이 같다면 결정론적 동일 함수는 같은 행동을 내므로, 관측만으로 자기 유닛을 식별할 수 있는지부터 확인해야 한다.

② 한 모델당 학습 시드 하나, 대진당 반복은 다섯 세트

총 2,100경기는 모든 학습 시드의 검증을 뜻하지 않는다. 참가 모델은 대부분 seed 11이며 v9는 22, v1~v6는 각 체크포인트의 기존 시드다. 이번 리그의 5회 반복은 환경·행동 난수 반복이다. 각 버전의 모든 체크포인트 중 최고를 재선정한 실험도 아니다. 모델별 시드·step·경로를 아래에 공개했다.

③ 순위 차이와 인과 효과를 혼동하지 않는다

v7 Rewired 90.0% 대 FlyWire 89.5%는 한 경기 차이이며 직접 대결은 5:5다. 생물학적 연결 구조가 이점을 줬다는 근거는 없다. 반대로 그래프 방식이 불필요하다고 결론낼 수도 없다. v6보다 v7이 더 낫다는 근거도 없다. v9와 v10의 0.5%p 차이 역시 critic 설계 개선을 입증하지 않는다. 모델별 대진의 초기 배치는 서로 달라 상대를 통제한 공통 맵 재평가가 필요하다.

④ 행동 proxy·평균·표본 추출의 한계

주요 행동 비율은 각 경기 내 비율을 계산한 뒤 200경기를 동일 가중 평균했다. 방향 히스토그램은 모든 유닛-step을 합산하므로 긴 경기에 더 큰 가중치가 있다. turn은 연속된 비정지 행동의 방향 차이가 약 45°를 넘는 지표이며 단순 행동 변경 횟수가 아니다. 위치 이동·팀 분산은 관측상의 값이고 의도·성공을 뜻하지 않는다. 추론 p50/p95는 각 경기 3개 chunk 표본이며 환경 속도나 단독 실행 벤치마크가 아니다.

⑤ 재현성과 원본 보존

완료 cell 2,100개, 고유 task ID, 210개 대진, 대진당 5회×2진영, 모델당 200경기, 자연 종료 여부와 기존 요약의 승무패를 대조했다. 초기 snapshot과 종료 chunk를 각 2,100개씩 저장 해시와 대조하고, 사용한 분석 관련 소스 해시도 확인했다. 전체 trace 파일을 모두 다시 해시 검증하거나 게임을 재실행한 것은 아니다. 기존 실험 파일은 수정하지 않고 별도 분석 JSON·HTML만 생성했다.

06 / NEXT PROJECT

다음 버전은 무엇부터 바꿔야 하는가

성능 개선을 ‘큰 모델 하나 더’로 시작하지 않는다. 실패 원인을 분리할 수 있는 작은 검증을 먼저 통과시킨다. 아래는 새로 실행하지 않은 제안이다.

P0
학습 전에

판정 기준과 자기 식별 계약 확정

공식 점수·runner reward·관측 점수를 한 경기에서 동시에 기록하고 불일치 원인을 확인한다. 허용 입력에 유닛 ID·메모리·공동 행동 선택이 포함되는지 확정한다. 동일 관측을 받는 팀원끼리 다른 행동을 해야 하는지 명시한다.

산출물 판정·입력 계약표통과 기준 설명되지 않은 판정 불일치 0건
P1
기준선부터

planner가 성능의 얼마를 만드는지 분리

같은 planner 소스·역할·입력 계약으로 planner-only, v6 residual, v7 Rewired, v7 FlyWire를 비교한다. keep/override 비율, 변경 유닛, 목표·경로·반납 성공을 기록한다. 기존 v4는 별도 참고 기준선으로 유지한다.

4조건 풀리그 6대진 × 20배치 × 2진영 = 240경기

이후 3개의 사전 고정 학습 시드 구성으로 반복하면 720경기다. 같은 초기 배치 목록을 모든 조건에 공통 적용한다.

P2
원인 가설 검증

직접 행동 정책의 ‘귀환 완주’ 개선

v9·v10의 목표 유지 시간, 최초 획득 시간, 획득 후 반납 전환율, 벽 인접 무이동을 먼저 계측한다. 계약이 허용하면 목표·역할·자기 위치 표현을 보강한다. 허용하지 않으면 관측만으로 가능한 목표 표현과 확률적 대칭 깨기를 검증한다.

1차 3조건 × 4고정 상대 × 10배치 × 2진영 = 240경기

조건: 기존 actor / 계약 내 목표 지속성 보강 / 대칭성 처리 보강. 상대: 정지·무작위·수집형·planner 기준선. 각 변경을 독립적으로 적용하고 동일 훈련 예산을 사용한다. 유닛 ID를 임의로 주입하지 않는다.

P3
채택 전 검증

새 배치·새 구조·다른 시드로 확인

개발용 배치와 최종 검증용 배치를 분리한다. 지원되는 다른 벽 배치가 있으면 포함하고, 없으면 ‘고정 지형 내 배치 일반화’로 범위를 제한한다. 후보 선택을 잠근 뒤 학습 시드를 추가 확인한다.

제안 3시드 × 4고정 상대 × 20검증 배치 × 2진영 = 480경기 / 후보

사전 채택 기준 예: 대응된 배치 기준 승점률 차이 +5%p 이상, 두 진영 모두 유지, 반납 전환율 개선, 추론 시간·오류율 악화 없음. 이는 제안된 목표이며 이미 달성한 결과가 아니다.

권장 진행 순서: P0 → P1·P2 → P3

최초 P1·P2는 합계 480경기 규모로 원인을 좁힌다. 큰 리그 반복은 원인이 확인된 후보에 한해 수행한다. 경기 시간은 상대·정책에 크게 좌우되므로 이전 전체 평균으로 새 실험 시간을 보장하지 않는다.
