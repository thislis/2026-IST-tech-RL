# 프로젝트 디렉터리와 경로 처리

2026-10-09에 호환 심볼릭 링크를 제거하고 실제 파일을 재배치했다. 공통 코드는 `code/shared/`, 버전별 코드는 `code/vN/`, 초기 코드는 `code/pre_v1/`에 있다. 버전 디렉터리는 해당 버전에만 존재하는 파일이 있을 때 생성한다.

- 계획·분석·직접 작성한 보고서: `docs/<버전>/`
- 버전 간 공통 이슈: `docs/issues/`; 초기 보고서: `docs/pre_v1/reports/`
- 공통 이력·게임/제출 규격: `docs/common/`
- 실행 로그와 자동 생성 보고서: `logs/<버전>/`, `logs/<버전>/reports/`
- 가중치: `artifacts/checkpoints/<버전>/`; v7 이후 run 내부 체크포인트는 원래 `logs/<버전>/` 구조를 유지
- 제공 게임 빌드: `artifacts/builds/`
- 그래프/학습 데이터: `artifacts/data/`
- 제출 산출물: `artifacts/submission/`
- 과거 소스 보관본: `artifacts/source_snapshots/`

`code/shared/project_paths.py`가 물리적 루트를 찾고 패키지 경로를 설정한다. 여러 버전이 공유하는 `blackout_rl` 패키지는 실제 버전별 디렉터리를 검색한다. 기존 기록에 저장된 경로는 `code/shared/legacy_paths.json`으로 읽을 때 해석한다. 이 파일은 심볼릭 링크를 생성하지 않으며 기록이나 등록 체크섬을 바꾸지 않는다.

관전용 과거 모델은 가중치 해시를 계속 검사한다. 경로 변경이 있었던 추론 소스는 `code/shared/relocation_sources.json`의 변경 전·후 해시를 검사하여 이후 미등록 변경을 거부한다. v6의 과거 planner는 기존 Git 커밋에서 읽는다. 따라서 관전에는 저장소 이력과 로컬 가중치/그래프 자료가 필요하다.

실행 명령은 프로젝트 루트를 기준으로 한다. 문서의 Markdown 링크는 각 문서 위치에서 계산한 상대 경로이며, `logs/`와 `artifacts/` 링크는 로컬 자산이 있는 작업 공간에서만 열린다. 새 clone에는 해당 파일이 포함되지 않는다. 전체 테스트 실행 방법은 [루트 README](../../README.md)를 따른다.

새 실험은 새 위치의 소스를 등록한다. 예전 소스 해시로 등록된 실험의 재개 검사는 계속 엄격하게 적용된다. 소스가 달라졌다면 별도 실험 이름과 등록을 사용한다. 오래된 동결 pilot 런타임은 당시 소스 보관용이며, 재배치 후 현재 환경에서 직접 재실행하는 용도로 사용하지 않는다.

`.gitignore`는 `logs/`, `artifacts/`, 로컬 환경, 가중치, 캐시와 비밀 설정을 제외한다. 코드·설정·의존성 lock·제출 템플릿·런처·직접 작성한 문서는 포함한다. 기존에 추적 중인 파일은 `.gitignore`만으로 추적이 해제되지 않는다. Git 상태의 이동/삭제는 로컬 데이터 삭제와 구분해야 한다.
